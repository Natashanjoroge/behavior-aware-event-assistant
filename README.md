# Behavior-Aware Event Assistant

A web-based behavior-aware assistant for personalized student event recommendation using user preference modelling.

## Project Stack
- React.js
- Flask
- Python 3.11
- PostgreSQL
- ALS / WRMF recommendation model

## Main Modules
- Student Event Discovery Interface
- User Interaction Logging
- Preference Modelling
- Recommendation Engine
- Organizer Analytics Dashboard
